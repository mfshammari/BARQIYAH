# خطوط بطاقة الدعوة المولَّدة

تُحمَّل من هنا وقت التشغيل (لا من Google Fonts) لتوليد صورة الدعوة في
`/api/invite-card/[kind]/[id]`:

- `amiri-*` — Amiri (SIL OFL 1.1) — نصّا الدعوة {{1}} و{{2}}.
- `ibm-plex-sans-arabic-*` — IBM Plex Sans Arabic (SIL OFL 1.1) — سطر الموعد والمكان.

ملفات TTF مأخوذة من حزم `@fontsource` (مقسّمة: arabic + latin).
